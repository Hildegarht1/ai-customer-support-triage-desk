# GitHub Publish Checklist

## Before Uploading

- Confirm there are no API keys, bot tokens, or credentials in any file.
- Export n8n workflows without credentials.
- Add screenshots with sensitive values hidden.
- Use fake customer data only.
- Make sure `README.md` explains what the project does.

## Recommended GitHub Repository Name

```text
ai-customer-support-triage-desk
```

## Short GitHub Description

```text
Webhook-based AI support automation using n8n, Telegram, Google Sheets, and Gemini.
```

## Application Project Summary

```text
Built a webhook-based support automation system with n8n, Telegram, Google Sheets, and Gemini API. The workflow normalizes incoming ticket data, handles structured JSON responses, classifies urgency and intent, searches a knowledge base, drafts support replies, routes escalation/approval decisions, and records audit logs for operational visibility.
```
