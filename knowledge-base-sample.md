# Sample Knowledge Base

Use these as rows in the `Knowledge Base` sheet.

## KB-001: Billing Plan Upgrade Delay

Keywords:

```text
billing, upgrade, plan, account, free, paid, dashboard access
```

Answer:

```text
Plan upgrades are usually reflected in the account within a few minutes, but in some cases they may take up to 24 hours. If the customer has already been charged and still cannot access paid features, support should verify the payment status and account email before making changes.
```

Escalation rule:

```text
Escalate if the customer cannot access paid features needed for active team work.
```

Owner:

```text
Billing
```

## KB-002: Password Reset

Keywords:

```text
password, login, reset, access, forgot
```

Answer:

```text
Customers can reset their password from the login page by selecting Forgot Password. They should use the email address connected to their account. If the reset email does not arrive after 10 minutes, they should check spam and confirm the email address with support.
```

Escalation rule:

```text
Escalate if the customer reports suspicious login activity or account takeover.
```

Owner:

```text
Technical Support
```

## KB-003: Automation Dashboard Not Loading

Keywords:

```text
dashboard, loading, blank, automation, page error
```

Answer:

```text
Customers should first refresh the page, clear browser cache, and try a different browser. If the issue continues, support should collect browser type, screenshot, account email, and approximate time the issue started.
```

Escalation rule:

```text
Escalate if multiple users from the same workspace are affected.
```

Owner:

```text
Technical Support
```

## KB-004: Cancel Subscription

Keywords:

```text
cancel, subscription, billing, renewal, refund
```

Answer:

```text
Customers can request cancellation from account settings. Refund eligibility depends on the billing policy and must be reviewed by a human support agent. AI drafts should not promise refunds.
```

Escalation rule:

```text
Always send refund-related cases for human review.
```

Owner:

```text
Billing
```
