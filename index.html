What The Automation Does

The system turns an unstructured customer message into a tracked operational ticket with classification, routing, draft response, and audit visibility.

1. Intake Telegram trigger receives a customer support message through a webhook.
2. Normalize n8n creates ticket IDs, timestamps, contact fields, and attachment metadata.
3. Classify LLM or fallback logic classifies intent, department, sentiment, urgency, and risk.
4. Retrieve Google Sheets knowledge base rows are matched against the message and ticket context.
5. Route Low-risk replies go for approval; urgent or risky cases escalate to an admin.

Architecture

Built as a low-code automation system with production-minded concerns: environment variables, credential isolation, persistent storage, structured outputs, and audit logging.

Workflow Runtime

Self-hosted n8n runs locally with Docker Compose and persistent volume storage.

Integrations

Telegram handles message intake and admin alerts. Google Sheets stores tickets, KB rows, and audit logs.

Automation Logic

Code nodes parse JSON, match knowledge-base entries, and decide escalation or approval paths.
